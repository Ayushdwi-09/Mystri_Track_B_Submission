# Handover

## Time

Total assessment work time: 3 hours 42 minutes, including 18 minutes of revision.

## Run

From the `track-b` directory:

```text
python experiment.py
python -m unittest discover -s tests -v
```

Python 3.10+; standard library only. No credentials, external services or paid APIs are required.

## Outputs

- `output/experiment_queue.csv` — classification of every request as PROPOSE, REVIEW or EXCLUDE.
- `output/summary.json` — reproducible snapshot counts generated by `experiment.py`.
- `DECISION.md` — decision and evidence.
- `SOURCES.md` — external research and limitations.

## Tool / AI decisions

I used Python 3.13 for reproducible CSV analysis, implementing the deterministic rules engine, generating experiment outputs and running verification tests. I used ChatGPT (GPT-5.6 Luna) for analysis support, research planning, reasoning through alternatives, and drafting/reviewing the decision note and handover.

The actual follow-up classification was implemented as deterministic Python rules rather than an LLM decision, so the same supplied inputs produce the same outputs on rerun. External research was limited to primary Microsoft documentation and Microsoft India pricing because Power Automate was evaluated as one alternative.

AI-generated calculations were not used as evidence. Calculated outputs and classifications were generated locally from the supplied CSVs and independently verified by rerunning the experiment and testing key edge cases.
